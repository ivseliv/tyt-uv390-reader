# TYT Reader и TYT CPS MD‑UV390 V2.42

Матрица описывает штатный кодплаг MD‑UV380/390 размером 852 533 байта. **«Правка» означает сохранение в новый локальный RDT на основе открытого файла.** Просмотр, изменение документа, экспорт и печать работают на Mac без подключения рации. Для переноса настроек по USB предусмотрена отдельная команда «Записать настройки в рацию…». Её возможности описаны в строке Program → Write data.

### Разделы дерева CPS

Английские названия и порядок воспроизведены по разделу `[TreeMainMenu]` файла `english.lang` из Windows CPS V2.42. У TYT Reader дополнительно вынесены «Одиночный работник» и «Таймеры сканирования». [Дистрибутив TYT MD‑UV390 Software 2.42](https://www.tyt888.com/uploads/file/20260130/20260130094315_9270.zip) · [Каталог TYT](https://www.tyt888.com/search.html?keyname=390)

| Раздел CPS 2.42 | Что можно сделать в TYT Reader | Предел |
|---|---|---|
| Basic Information | Посмотреть модель, диапазоны из заголовка RDT, сохранённые дату программирования и версию CPS при наличии. | Только просмотр. По USB модель определяется из ответа устройства, диапазоны из заголовка файла недоступны. |
| General Setting | Изменить имя, основной и три дополнительных Radio ID, режим передачи, заставку, VOX, уровень микрофона, оповещения и таймеры вызова, сканирования и одиночного работника. | Пароли включения и программирования, PIN в редактор не выводятся. |
| Menu Item | Посмотреть и изменить время показа меню и доступность известных пунктов, включая вызовы, сканирование, отображение, GPS и зоны. | Флаги задают видимость пунктов меню на рации. |
| Buttons Definitions | Назначить функции боковых клавиш и порог долгого нажатия. Настроить шесть быстрых действий и привязки десяти цифровых клавиш. Для быстрого действия DTMF выбираются система и номер Encode 1–32. | Доступные быстрые действия — вызов DMR, сообщение по шаблону и DTMF. Номер Encode 0 снимает назначение. |
| Text Message | Добавить, изменить и удалить каждый из 50 шаблонов RDT. До 144 кодовых единиц UTF‑16 на шаблон. | При полном чтении USB и RDT доступны все 50 слотов. |
| Privacy Setting | «Считать настройки» и затем «Privacy → Basic и Enhanced (USB)…» показывают ключи из кодплага. «Сервис → Считать Universal Privacy по USB…» отдельно показывает номер, имя и тип для позиций 1–255. При выборе своего исходного DEC можно посмотреть локальное значение совпадающей по номеру, имени и типу записи. Через меню «Сервис» можно редактировать Basic и Enhanced в локальном RDT, а также создать, изменить и сохранить файл Universal DEC. | Для Basic доступны 16 позиций. Для одной таблицы Enhanced можно выбрать раскладку 8 × 128 бит или 4 × 256 бит. JSON хранит назначения каналам. В Universal два 64-байтных типа доступны в позициях 1–16. На прошивках D219.43 и D219.62 имена и типы приходят по USB, а поля значений прошивка заполняет нулями. [Разбор автора UV390 Studio](https://dmr-zone.ru/issues/считывание-ключей-из-радиостанции/) |
| Digit Emergency System | Создавать, переименовывать и удалять профили. Изменять общие флаги, таймеры, режим, повторы, время открытого микрофона и возвратный канал. | При полном чтении USB и RDT доступны общие параметры и 32 слота. |
| Digital Contact | Добавить, дублировать и удалить контакт, изменить имя, DMR ID, тип вызова и признак оповещения. | До 10 000 контактов RDT. Поддержаны групповой, индивидуальный и общий вызов. База пользовательских позывных загружается в оригинальной CPS отдельной командой. |
| Digital RX Group Call | Создавать и переименовывать группы, подбирать и упорядочивать контакты, удалять группы. | До 250 групп по 32 контакта в RDT. |
| Zone Information | Редактировать независимые упорядоченные списки A и B, добавлять, дублировать и удалять зоны. | До 250 зон, по 64 канала на каждой стороне. |
| Scan List | Составить список и порядок каналов, выбрать два приоритетных и возвратный канал, изменить времена удержания и опроса. | До 250 списков по 31 каналу. |
| Channel Information | Добавлять, копировать и удалять каналы FM/DMR. Редактировать частоты RX/TX, полосу, мощность, тайм-аут, тоны, контакт, RX-группу, сканирование, Color Code, Time Slot и поддержанные флаги. | До 3 000 каналов. Шаг записи частоты 10 Гц. Имена каналов и основных списков — до 16 кодовых единиц UTF‑16. Возможности других прошивок не проверялись. |
| DTMF Signaling | Четыре системы с восемью таймерами, самопрослушиванием, режимом PTT ID, групповым символом и строками KeyUp/KeyDown. Можно редактировать 32 последовательности передачи и ID в восьми позициях обычного декодера, привязывать Encode к быстрому доступу. | Для служебных декодеров показывается отметка о типе записи. Старый USB-снимок позволяет ввести последовательности вручную. При переносе на RDT неизвестные позиции наследуются от шаблона. |
| VFO Mode | Настроить VFO A/B, режим дисплея, частоты RX/TX, шаг, мощность, режим «Только приём» и список сканирования. Для FM доступны полоса и отдельные субтоны CTCSS/DCS на приём и передачу. Для DMR — контакт, группа приёма, Color Code и Time Slot. | Редактор проверяет ссылки на контакты и списки по их номерам. Раскладка соответствует записи канала UV390, у которой вместо имени хранится шаг VFO. [Разметка qdmr](https://github.com/hmatuschek/qdmr/blob/v0.15.1/lib/uv390_codeplug.hh#L140-L159) |
| GPS System | Создавать и удалять профили, изменять период, контакт назначения и возвратный канал. Каналы содержат отдельные флаги GPS. | До 16 слотов RDT. Показ живых координат рации недоступен. |

Basic и Enhanced находятся на одной странице USB с концом таблицы SMS и началом таблицы тревог. Если эта страница недоступна, раздел «Сведения о рации» показывает примечание к чтению. ### Файлы и операции с устройством

| Операция | Возможности и ограничения |
|---|---|
| New / Open | Пустой локальный документ можно сохранить в JSON. «Новый из шаблона RDT…» открывает копию настроек выбранного RDT для редактирования и сохранения под новым именем. Открываются RDT, JSON, YAML/YML qdmr и поддерживаемые CSV. |
| Save / Save As | В JSON сохраняется снимок поддержанных полей. Новый RDT можно сохранить на основе открытого RDT. Для USB, JSON и совместимого YAML «RDT по шаблону…» переносит основной DMR ID и основные поля пяти таблиц в новую копию выбранного RDT. Расширенные параметры и прочие разделы берутся из шаблона. Отсутствующая в старом снимке таблица наследуется от шаблона, явно пустая очищается. Результат повторно читается до сохранения. |
| CSV, каналы и контакты | Таблицы каналов (51 поле) и контактов (4 поля) с английскими заголовками CPS 2.42 можно открыть и импортировать в черновик. Из полного снимка USB, RDT или JSON с нужными полями экспортируется CSV CPS. Для неполных данных и смешанных типов контактов используется CSV Reader. Формат определяется отдельно для каждой таблицы. |
| YAML qdmr | В обе стороны передаются DMR ID и основные таблицы совместимых настроек. Экспорт проверяет ссылки и сообщает номер проблемной записи, в том числе при включённом Privacy или полосе FM 20 кГц. Для таких кодплагов доступны JSON и локальный RDT. Дополнительные поля восстанавливаются в пределах данных снимка. |
| Print / Print Preview | Системный диалог macOS печатает сводку по заполненным разделам и позволяет сохранить её в PDF. Отдельное окно предварительного просмотра и печатные бланки Windows CPS не воспроизведены. |
| Program → Read data | Одна включённая штатная рация, кабель программирования и `libusb`. При чтении проверяются USB-описатели и модель MD‑UV380/390. В снимок входят поддержанные публичные диапазоны. |
| Program → Write data | Из штатного RDT, полного снимка TYT или его черновика можно перенести заполненные позиции каналов, зон A/B, цифровых контактов, сканирования и групп приёма 54–250. Программа сверяет модель и DMR ID, показывает число изменённых записей и запрашивает подтверждение. Перед стиранием секторов сохраняет новую резервную копию `.tytbackup`, после записи проверяет содержимое повторным чтением. Пропущенные в документе позиции сохраняются в рации. Через «Сервис → Восстановить настройки из резервной копии…» можно вернуть исходные секторы. Подключите рацию, с которой сделана копия. Программа сверяет модель, DMR ID и состояние секторов с сохранёнными данными до и после записи. При сбое питания возможна частичная запись сектора. На физической MD‑UV390 10 Вт с D219.043 запись пока не проверена. |
| Program → Write Contacts | Команда записи переносит контакты кодплага. Загрузка внешней базы абонентских позывных в этом режиме недоступна. |
| Program → Test Mode / Adjust | «Сервисная калибровка» открывает штатный .test размером 8192 байта. Доступны 46 строк, исходные значения и локальные правки. В отдельный JSON можно занести результаты измерения BER для A и B. Для нового .test нужна исходная сервисная таблица. Измерение прибором, включение передачи и применение к рации в этот режим не входят. |
| Edit → Time Setting | Дата последнего программирования доступна для просмотра. |

В YAML qdmr сохраняются ссылки между каналами, контактами, обеими сторонами зоны, RX-группами и списками сканирования. Дополнительные разделы включают известные поля TYT, SMS и позиционирования, если они присутствуют в файле. Импорт также распознаёт каналы AM/M17 и контакты DTMF/M17 qdmr. Это не добавляет соответствующие режимы в штатный RDT. [Формат qdmr](https://static.dm3mat.de/qdmr/manual.pdf) · [Импортёр YAML](import_qdmr.py)

На macOS проверялись импорт публичных RDT, YAML из qdmr 0.15.1 и локальный цикл «правка → новый RDT → повторное открытие». Открытие изменённых RDT и CSV непосредственно в Windows CPS 2.42 и программирование ими рации не проверялись.
